# Код

Стек стартового репозитория остаётся: один `index.html`, `style.css`, `app.js` без сборщика. Решения: [decisions.md](../decisions.md).

## JavaScript

- Обычный скрипт в браузере. `type="module"` на теге `script` не ставим.
- Имена привязок — таблица в спеке. Класс `editMode` и id элементов не меняются.
- Пустую задачу по-прежнему отсекает проверка значения поля, без `trim`.
- Перенос задачи — `appendChild` того же узла, не копия.
- `console` в итоговом `app.js` нет.
- Комментарий, который пересказывает строку, не оставляем. Комментарий «почему» оставляем только если причина не читается из кода. По текущим решениям таких мест нет.

## HTML и CSS

- Внешний вид совпадает со стартовой страницей, включая отсутствие зачёркивания у выполненных задач ([D-004](../decisions.md)).
- Анимация кнопки удаления (`rotateZ` за 200ms) остаётся.
- Prettier принимает `index.html` и `style.css`. Обход через `.prettierignore` запрещён заданием.

## Инструменты

Конфиг ESLint можно объяснить по блокам: рекомендованный набор, глобалы браузера, три добавленных правила, отключение стилевых правил в пользу Prettier. Чужой готовый набор правил не подключаем.
